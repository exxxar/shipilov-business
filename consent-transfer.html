Субъект персональных данных

Перечень передаваемых данных

Передаче подлежат следующие персональные данные (в объёме, необходимом для исполнения запроса пользователя):

  • имя;
  • номер телефона или идентификатор в Telegram;
  • адрес электронной почты;
  • текст обращения и тема запроса;
  • прикреплённые файлы (при наличии).

Цель передачи

Передача данных осуществляется исключительно в целях:

  • обработки входящего обращения и подготовки ответа;
  • связи с пользователем по его запросу;
  • обсуждения проекта и подготовки коммерческого предложения;
  • обеспечения технической работы сервисов, используемых Оператором.

Перечень третьих лиц (обработчиков)

Обработчики персональных данных

  • Хостинг-провайдер — для размещения файлов сайта и базы данных на серверах, расположенных на территории Российской Федерации.
  • Почтовый сервис (SMTP) — для отправки ответов на обращения пользователей и технических уведомлений.
  • CRM-система — при подключении, для учёта обращений и управления взаимодействием с клиентами.
  • Сервисы аналитики — при подключении, для улучшения работы сайта (сведения будут дополнены).

Все обработчики действуют на основании договоров с Оператором, обязывающих их соблюдать конфиденциальность и обеспечивать защиту персональных данных в соответствии с требованиями законодательства Российской Федерации.

Способы передачи

Передача данных осуществляется с использованием средств автоматизации, в том числе через защищённые каналы связи (HTTPS, API), а также путём предоставления доступа к базам данных обработчикам в объёме, необходимом для исполнения ими своих обязанностей.
