# Portfolio — Егор Шипилов

Файлы:
- index.html — лендинг
- style.css — стили
- script.js — анимации, счетчики, AJAX-форма
- send.php — обработчик формы
- .htaccess — clean URLs / HTTPS redirect
- robots.txt — правила индексации
- policy.html — политика обработки персональных данных

Перед запуском:
1. В index.html заменить REPLACE_EMAIL@example.ru.
2. В send.php заменить $recipient и $fromDomain.
3. В robots.txt заменить REPLACE_DOMAIN.ru и создать sitemap.xml.
4. В policy.html заполнить реквизиты оператора и фактические сервисы.
5. Заменить placeholder-фото AWARD/PHOTO/ADD PORTRAIT реальными файлами.
6. Проверить, что хостинг поддерживает Apache mod_rewrite и PHP.
7. Для production рекомендуется отправка почты через SMTP, а не PHP mail().
8. Проверить фактическую инфраструктуру обработки персональных данных и финальную редакцию политики до публикации.
